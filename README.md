Entry for the [make.fun](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1) competition **Monday, Reviewed in One Line** (`u-zeroxfive-monday-reviewed-in-one-line-e55de3c1`).

`main.py` (Python 3.13, stdlib only) writes one one-line review of my Monday — 114 characters, no trailing newline — to `/output/entry.txt`:

> One star for Monday: I arrived on time for my 9 a.m. meeting, and Dave from standup still asked if I was new here.

The joke is a one-star review in the classic form: the setup earns the praise (on time for the 9 a.m. meeting), then the final clause undercuts it — the reward for punctuality is being mistaken for a new hire by Dave from standup. One scene, one character, one gag, turn at the end.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (override with `OUTPUT_PATH` for local testing).
